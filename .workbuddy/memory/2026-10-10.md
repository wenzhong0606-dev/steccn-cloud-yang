### EAM 原型：引入 Bootstrap 5（全量，用户决策）
- 用户决策：通过 CDN 全量引入 Bootstrap 5 做布局/样式，减少手写样式。注：MDN 不托管 BS，改用 jsDelivr `bootstrap@5.3.3`（CSS+后续按需 JS bundle）。
- 关键级联层冲突与解法：原 `shared/style.css` 用 `@layer` 治理（tokens<base<layout<components<business<responsive），而 Bootstrap 是**非分层**样式，默认会压过分层样式。解法：用 `@import url(bs) layer(bootstrap)` 把 BS 归入 `bootstrap` 层并置于层顺序**最前（最低优先级）**，使我们的设计系统仍覆盖 BS；离线时自动回退到分层样式（优雅降级）。
- 令牌对齐：在 `shared/styles/令牌.css` 的 `:root` 与 `:root[data-theme=dark]` 中新增 `--bs-*` 变量，映射到现有 `--color-*` 品牌令牌（primary/secondary/success/danger/warning/body-bg/body-color/border-color/border-radius/link/font），BS 组件即继承品牌色，亮/暗主题一致。
- 参考页改造（equipment.html + equipment.js）：统计卡改用 BS `row g-3` + `col-6 col-md-3` + `card stat-card w-100`；表格加 `table table-hover`；工具条/弹窗按钮加 `btn` 系列；表单 `eq-*` 控件加 `form-control/form-select`、高级筛选 `filter-*` 加 `form-select`。**全部保留既有 id 与 JS 依赖**（node --check 通过，HTML 良构，关键 id 各 1 处）。
- 校验：style.css 层声明正确；equipment.js 语法 OK；equipment.html 标签平衡；search 等自定义控件未误加 BS 类。
