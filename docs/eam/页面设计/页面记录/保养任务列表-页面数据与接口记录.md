# 保养任务列表—页面数据与接口记录

日期：2026-10-11。页面：maintenance-task-list.html；候选记录，尚未正式建表或改后端。

## 页面操作

共享标题/面包屑、列表工具栏、无关键词前缀的筛选input-group、漏斗高级筛选弹窗、导出/刷新/列设置图标、DataTable/load-status/表内空态/分页。主操作从计划生成；行内按钮进入个人派工与执行详情。导入禁用，导出翻页读取当前授权范围全量JSON。

## 候选表与字段

候选maintenance_task保存id/code/name、equipmentId、planId/planVersion、versionWindowKey/occurrenceKey、scheduledAt/windowStart/windowEnd、status/revision/executionVersion及原发布snapshot。日期唯一约束为逻辑计划+设备+日期；跨版本重复日期返回原任务。task_assignment保存bindingRefs/resolvedPeople、primaryPersonId/collaboratorIds、assignedBy/At/reason；执行中改派不改原结果记录人。

maintenance_execution保存taskId/executionVersion、laborMinutes、materialRef、trial、安全许可snapshot、提交冻结snapshot/submittedBy/At。maintenance_item_result保存itemId、conclusion/value/evidence/followup、actorId/recordedAt。maintenance_anomaly_link保存来源task/item/version、稳定key、payloadSignature、pending_link/linked/failed、discoveryId/error。generation_request保存幂等键、请求人员、请求及原响应。task_audit保存前后字段快照与人员/原因/时间。设备、人员、岗位引用平台主数据；列表与详情是同一任务投影，不按页面建独立业务表。

## 候选接口列表

GET /maintenance/config；GET /maintenance/tasks（equipmentId/status/mine/keyword/page/pageSize）；GET /maintenance/tasks/{id}；POST /maintenance/plans/{id}/generate（activeVersion/expectedRevision/windowKeys/reason/idempotencyKey）；POST /maintenance/tasks/{id}/assign（expectedRevision/primaryPersonId/collaboratorIds/reason）；GET /maintenance/tasks/{id}/start-check；POST /maintenance/tasks/{id}/start、pause、resume、cancel；PATCH /maintenance/tasks/{id}/execution；POST /maintenance/tasks/{id}/discoveries；POST /maintenance/tasks/{id}/anomaly-links/{id}/retry；POST /maintenance/tasks/{id}/submit。命令带expectedRevision，执行带executionVersion；字段详见[页面登记](页面登记.json)的maintenanceTasksV1组。

## 权限和边界

接口校验实际人员角色；维修/外包仅能读取本人参与任务，其他合法EAM角色在当前模块设备范围只读。主管派工/未开工取消；主责开工/暂停/提交，主责与协作暂存及异常上报；主管或主责恢复。开工/恢复重新检查当前设备、人员资格、范围有效期与专业许可；资格失效演示场景阻断。设备授权范围当前复用维护接口equipment投影，正式租户/组织权限后续统一设计。

提交完整性包括必填项目、数值上下限、要求证据、正工时、试运行；空白可选项允许跳过。异常项须真实发现引用和处置说明；任何待关联异常须先重试。未开工可取消，已开工终止须独立审核后续接入。提交仅到待验收；独立验收/退回重执行/终止审核和档案同源聚合第三批。当前证据是受控文本引用，未增加附件上传。时间校验使用JSON asOfDate，是模拟日期而非实时调度。

所有数据/配置来自maintenance-data.js，页面经EamMaintenanceApi.request异步读取/写命令；task rules/API独立模块，共用计划存储与串行命令队列。异常复用EamProblemApi，来源字段结构化保存；跨mock非原子事务，先存关联意图、创建后保留发现编号，重试不重复。正式数据结构待全部模型完成后统一设计。
