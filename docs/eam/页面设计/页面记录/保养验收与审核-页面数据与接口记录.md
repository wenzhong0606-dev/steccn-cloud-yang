# 保养验收与审核—页面数据与接口记录

日期：2026-10-11。独立页面：maintenance-acceptance.html。菜单：日常维护 / 保养验收，属于M04任务闭环子入口。

## 页面与交互

统一标题、筛选input-group、图标高级筛选弹窗、表格load-status、列表内部空态、分页、导出、刷新、列设置。审核类型切换待验收和终止待审核；点击独立验收或终止审核进入任务详情的静态HTML命令表单。数据由预定义JSON经模拟接口获取，不另存审核队列。

## 候选表与字段

候选表为eam_maintenance_submission、eam_maintenance_acceptance、eam_maintenance_termination、eam_maintenance_termination_review；字段以页面登记.json的保养审核对象为准。保存执行版本、冻结提交、参与者集合、独立审核者、决定、理由、时间与证据；终止另含已完成工作、风险、持续控制、后续安排、责任人与期限。审核队列为任务与审核对象的查询投影，不新增队列表。

## 候选接口列表

GET /maintenance/reviews：审核类型、设备、个人范围、关键字及分页；返回授权队列和actions。
POST /maintenance/tasks/{id}/acceptance：expectedRevision、executionVersion、decision、reason；通过须独立核实项目/试运行与证据，有异常须评审遗留安排。
POST /maintenance/tasks/{id}/request-termination：版本、原因、已完成工作、风险、控制、安排、责任、期限、证据。
POST /maintenance/tasks/{id}/review-termination：版本、terminationRevision、决定、理由，通过须确认风险及后续安排。

## 状态与边界

参与执行、当前版本安全复核、记录或提交的人员不能独立验收；申请人及执行参与者不能审核终止。验收退回进入暂停并创建空白新执行版本，安全复核后重做；旧提交保留。终止待审冻结执行及改派，驳回保持暂停，批准变为已终止。验收和终止均不自动关闭异常、隐患、缺陷、故障、许可或使用限制。正式库表与接口仍待所有模型完成后统一设计。
