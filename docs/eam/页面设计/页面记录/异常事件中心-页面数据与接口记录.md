# 异常事件中心：页面数据与接口记录

日期：2026-10-10。页面ID：`abnormal-events`；[独立HTML](../../prototype/pages/abnormal-events.html)。

## 页面范围、角色与操作

入口：系统平台 → EAM模块 → 角色工作台/模块列表 → 本页。PC与移动端共享业务规则，顶部切换仅改变评审布局，不改变角色或单据状态。

发现提交、分诊、关联已有缺陷或新建缺陷/故障、无问题归档；详情及审计。证据为文本/受控编号，附件上传、隐患协同、草稿CRUD暂未实现。；入口修复：列表显示下一步/详情/工单创建；异常显式归档须留证；缺陷/故障/隐患线索登记打开发现表单，授权人员提交后进入核实分诊，生成独立问题。跨页action=triage定位表单，不仅跳转列表。

角色与操作授权见下方候选接口表；当前演示身份由评审控件切换，真实授权必须由正式平台身份与后端实施。删除/撤回/停用和历史规则参见[首批操作矩阵](../2026-10-10-首批页面操作矩阵与交互验收.md)。

## 本页界面治理记录

本页使用唯一公共样式入口、本地Bootstrap 5.3.3与五层CSS；主题、模块导航及键盘语义由公共UI层提供。业务范围以本页登记说明为准；模拟接口与正式候选接口应分别记录，主题偏好属于本机会话偏好。布局与状态验收须按[UI/UX规范](../HTML高保真页面UIUX审计与优化规范.md)及[本轮审计](../2026-10-10-首批UIUX审计与优化记录.md)执行。

## 关系与状态约束

设备为多数业务主关联；部位通过固定ID引用，名称为发现时快照；文件对象和对象关联分离。任务冻结标准/计划版本，结果引用任务；报告分流专项检查/工单，工单包含多个执行版本，验收指向实际执行版本。已发布/已执行对象不可覆盖或直接删除。

正式服务按租户、组织、设备与实际指派过滤。修改带revision，跨状态/重复请求按业务语义拒绝或幂等，审计记录人员、时间、原因和前后快照；不能仅用前端按钮授权。

## 候选接口列表（未接入）

路径是待合并的候选命名；当前HTML不发这些业务HTTP请求。文件上传会话和预览地址必须由正式服务分配；不得把本地拟议目标当成真实上传地址。

| 方法 | 候选路径 | 请求字段/查询 | 返回对象 | 权限/前置条件 |
| --- | --- | --- | --- | --- |
| GET | `/eam/discoveries` | filters,page,size | 发现列表投影 | 范围授权 |
| GET | `/eam/discoveries/{id}` | id | 发现、关联及审计 | 范围授权 |
| POST | `/eam/discoveries` | 设备、现象、发生时间、证据、幂等键 | 新发现及version | 现场授权 |
| POST | `/eam/discoveries/{id}/triage` | expectedVersion,types,existingId,ownerId,dueAt,failureMode,impact,reason | 分诊与独立问题关联 | 工程师/主管 |
| POST | `/eam/discoveries/{id}/archive` | expectedVersion,reason,evidence | 已归档发现及核实证据/人员/时间 | 工程师/班组长；未关联问题的高优先级拒绝，关联问题须全部关闭；不改变问题状态 |
| GET | `/eam/defects` | filters,page,size | 缺陷投影 | 范围授权 |
| GET | `/eam/defects/{id}` | id | 缺陷与发现关联 | 范围授权 |
| POST | `/eam/defects/{id}/submit-verification` | expectedVersion,reason,evidence | 待验证缺陷 | 授权处置人 |
| POST | `/eam/defects/{id}/verify` | expectedVersion,decision,reason,evidence | 关闭或退回 | 独立工程师/主管 |

通用异常候选：400字段校验、401未认证、403越权、404对象不存在、409版本/状态冲突、413大小超限、415文件类型不匹配、503暂时不可用。分页请求建议包含page/size和稳定排序；正式错误格式和幂等契约后续统一。
