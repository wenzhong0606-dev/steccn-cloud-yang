# 档案同源回读与列表组件统一记录

日期：2026-10-11。范围：HTML 原型和异步 JSON 模拟接口，未接正式业务服务。

## 数据回读

设备档案通过 `archive-maintenance-api.js` 聚合异常、缺陷、故障、维修工单、隐患及人员接口。按 equipmentId 筛选；工单继续遵守来源接口的指派可见范围；履历仅投影可见对象的审计。维修与故障历史样本明确标识未关联当前流程。

概况“当前未结事项”统计未分诊异常、未关闭缺陷/故障/隐患及未关闭工单，是事项数量，不能解释为去重后的故障数量。已分诊异常不重复计入。健康状态为业务问题汇总，运行状态仍来自独立运行信号。隐患限制按 restriction.status 判断，工单关闭不代表解除；来源限制从来源页面独立放行，档案不调用旧放行命令。

候选投影字段：equipment_id、source_kind、source_id、source_state、source_version、event_at、source_updated_at、restriction_type/scope/status、audit_object_id/action/before/after/actor_id/at。它们是跨领域查询投影，**本批不新增重复业务表**；正式表结构与接口仍在全部原型完成后统一设计。

接口记录：GET /equipment/{id}/archive；GET /equipment/{id}/domains/{failure,repair,risk,restrictions,related,history,audit}。来源 GET /discoveries、/defects、/failures、/work-orders、/hazards、/people、/work-config。筛选和分页在原型的授权数据副本中执行；正式查询需统一 page/pageSize/keyword/status/sourceKind，返回 items/total/page/pageSize，未实现正式服务分页。

## 统一组件

共享入口 `EamUiComponents`：DataTable、FilterBar、AdvancedFilter、Pagination、LoadStatus。独立页面保留 HTML 结构及业务列，不拼装整页。

13 个主列表均采用高级筛选弹窗；分类与参数、功能位置补齐状态筛选和分页。设备档案记录页签增加状态/来源高级筛选。弹窗修改为草稿，应用后才更新列表；取消或 Escape 恢复原值，重置只清空弹窗草稿。

分页统一由 paginationText 生成“共 X 条 · 第 Y / Z 页”，X 为当前筛选命中总条数，不是本页条数；零记录显示第 1 / 1 页，前后页禁用。保留现有不同业务每页数量，本批未统一为可切换 pageSize。

档案列表复用 Bootstrap 表格增强、操作按钮、单行截断和 load-status。移除重复的记录标题，将来源业务入口放入清单标题栏；清单页头、来源信息、加载状态和分页固定，表格区域内部滚动。

## 验收与边界

88 项 Node 测试通过；样式工程 9 文件无错误；25 HTML / 452 文档链接一致性检查无错误。

浏览器实测 13 个主列表高级筛选弹窗；档案维修筛选取消保留 4 条、应用待技术验收得到 1 条；关联业务 20 条可从第 1/3 页切换第 2/3 页。1366×768 下分页底边与档案内容容器底边一致，表格 overflowY=auto。模拟接口依然不能作为真实后端或体系合规验收证据。

遗留：专业领域完整 CRUD、强类型参数校验、完整性修复工作流尚未完成；配置维护原有会话直接写入边界仍需后续统一接口迁移；文档资料为既有卡片列表，媒体图库不强制套用表格。

四种尺寸最终复测（1366×600、1366×768、1920×1080、390×844）分页均在可见区域，表格有效高度分别为98/258/554/138px。证据：[逐页与尺寸验收](../维护业务原型/档案列表组件统一验收.json)、[PC效果](../维护业务原型/档案列表组件统一效果.png)。
