# 设备档案图片与3D改造实施与验收记录

日期：2026-10-12。依据：用户确认的媒体页签设计及[逐页签产品审查报告](设备档案逐页签产品审查报告.md)。范围为现有 HTML 模拟原型，浏览器验收端口 **8765**。

## 页面与业务边界

媒体页签使用 Bootstrap 分段按钮，在设备图片与 3D 模型间切换。主要查看区与资源信息通过响应式栅格排布；窄屏先看图片或模型，再看版本信息。媒体页签改为主内容自然滚动，不再由档案内部固定高度截断查看区；其他页签保留原阅读框架。

设备图片保留主查看区、缩略图、前后切换、放大轮播、资料信息、设为主图和移除关联。示意图片单独列示缩略预览，不因上传实拍图片而消失，不参与设备主图判断。无实拍时使用紧凑空态并默认展开示意分组，避免首屏出现大面积无内容区域。摘要只读取明确的 isPrimary 图片；内容缺失或解码失败有独立提示。无指定主图时显示占位，不用相册首图或产品型号示意图替代。

3D 模型有独立资源清单，显示设备、文件版本、上传人、接收时间、大小与内容来源。选择版本后显式加载；查看选择不等同审批生效版本。模型不进入技术文档列表。资源管理的模型查看入口进入设备档案的 3D 视图。

真实渲染使用本地固定版本 `@google/model-viewer 4.4.0`，按需加载，保留许可证与文件哈希。支持自包含 GLB/glTF 的旋转、鼠标/触摸缩放、重置视角、全屏及退出全屏。默认不自动旋转、不启用 AR。依赖包说明见[版本与来源](../../prototype/vendor/model-viewer/版本与来源.md)。

移除固定 MX-2400 CSS 假模型和固定轴承/测点关联入口。未配置真实模型节点与设备部件关系时不显示定位能力。独立“查看演示模型”按钮加载本仓库生成的三节点 GLB，明确标注非当前设备工程资产，不自动填充任何设备的模型空态。

## 状态与错误处理

| 状态 | 页面行为 |
| --- | --- |
| 未关联模型 | 设备模型数量为零，查看区明确空态，仍可看设备图片或主动打开独立演示 |
| 仅有元数据 | 显示设备与版本，禁用加载和内容下载，提示重新关联本机内容 |
| 文件已选中 | 显示所选资源信息，提供加载入口 |
| 正在加载 | 读取、检查并渲染，加载按钮禁用；切换对象取消旧请求显示 |
| 加载成功 | 开放旋转、缩放、重置和全屏，显示所选名称与版本 |
| 文件头/场景损坏 | 在加载查看器前返回具体格式错误；允许重试或重新关联 |
| 外部纹理/几何依赖 | 提示导出内嵌资源 GLB，不尝试从外部 URI 读取未关联资源 |
| Draco/KTX2/Meshopt 压缩 | 当前未配置额外解码器，明确提示导出未压缩自包含模型 |
| 运行时错误/超时 | 错误说明与重试，不保留旧模型伪装加载成功 |
| 目录读取失败/持续读取 | 清空旧目录、主图与操作资格；不能通过下一张恢复旧资源 |

异步模型挂载先使用离屏宿主，通过请求序号后才替换当前查看区，防止迟到的加载覆盖新选择；取消、刷新和离页释放对象 URL。下载、主图维护、移除仍由现有权限和领域命令控制，报废设备只读。

截图与窄屏实测结果放在[媒体改造证据目录](../../验收证据/设备档案媒体改造/)。DOM 验证不替代浏览器渲染或几何布局证据。

## 后续范围

本批提供实际本地模型查看，不代表 CAD 转换、压缩模型解码、工程节点绑定或正式服务器上传已完成。文件内容仍仅保存在当前浏览器，业务权限为模拟原型权限，未接正式后端或 CI。

后续专业模型需统一定义模型审批/生效版本、部件及测点映射、模型替换后的绑定核验、资源服务与权限接口。其余页签的专业筛选、时间轴/清单切换、运行趋势阅读和移动端业务重排继续按第二批阅读框架推进。
