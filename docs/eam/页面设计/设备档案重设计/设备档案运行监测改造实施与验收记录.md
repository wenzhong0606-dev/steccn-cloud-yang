# 设备档案运行监测改造实施与验收记录

日期：2026-10-12。范围：设备档案原型的运行监测页签。

## 页面与功能

- 使用 Bootstrap 表单、按钮、导航及状态提示，默认展示趋势图；原始数据通过切换查看，不再与小图堆叠。
- 支持温度、累计运行小时测点。图表、原始数据、详情使用所选测点的单位与阈值，累计小时不套用温度上限。
- 支持全部采样、快照前24小时、快照前7天、自定义区间。相对范围以来源快照为基准；自定义起止时间按中国标准时间解释，反向范围明确报错。
- 仅质量合格、时间有效、数值有效的采样参与曲线；无效采样保留在原始记录并断开曲线。提供有效、无效和越限数量、质量筛选及分页。
- 展示来源快照、阈值依据、静态示例声明；失效信号明确提示当前运行状态未知。加载或错误期间暂停旧图重绘。
- 采样点支持悬停、键盘读值及详情。图表按容器宽度重排坐标，手机保留可读字号和较大的采样点命中区域。
