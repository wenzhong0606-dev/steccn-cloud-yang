# 参数校验与完整性修复设计记录

日期：2026-10-11。实现范围：设备档案 HTML、预定义 JS JSON、异步模拟接口；未变更正式数据库或现有调用方。

## 技术参数

模板定义返回 type、unit、min、max、precision、template。当前 MIXER-V3 的四个示例参数采用 number/range；数值输入和范围双输入共用固定单位及模板提示。上下限仅为原型演示边界，不作为厂家或体系限值。

PATCH /equipment/{id}/domains/parameters 保留 id/revision/content/reason 请求兼容性；接口按模板将 content 校验为 typed 值，拒绝非法类型、单位、精度、越界和范围倒置。无权限、报废设备、版本冲突或失败场景不写入。成功保存更新记录版本，审计保留参数对象、前后内容与 typed 值、模板版本、操作者和原因。

候选结构：parameter_definition(id,type,unit_id,min,max,precision,template_version)；equipment_parameter(equipment_id,definition_id,numeric_value,range_lower,range_upper,revision,updated_at)；parameter_change_audit(object_id,before_json,after_json,template_version,actor_id,reason,changed_at)。此处仅记录正式设计候选，不生成建表语句。

## 完整性与补录

GET /equipment/{id}/domains/completeness 从四个存在性规则升级为基础字段阶段适用规则、参数定义校验、模板适用检查。混合机示例共13条检查：8个基础字段、4个参数、1个模板检查。

编码、名称、型号、位置、负责人在全阶段必填；制造商、序列号、投用日期在用及后续阶段必填，草稿阶段显示不适用。额外核对负责人可选范围、投用日期合法性与设备编码重复。未绑定模板显示待配置，不套用混合机参数。报废设备及非维护角色不给补录操作。

基础缺项或错误字段进入补录表单；负责人候选项由接口 JSON 返回。若同时缺少其他基础必填字段，表单一并呈现，避免保存时陷入逐项校验死锁。参数问题进入参数页签，模板问题进入分类与参数模块。

PATCH /equipment/{id}/domains/base 请求 field/value/values/revision/reason。只允许本批白名单字段及尚缺的额外基础字段，继续使用设备资料业务命令的权限、编码、负责人、长度及版本规则。保存返回最新设备记录并重新读取检查清单、概况；不会自动改变运行状态、许可或隐患结论。

候选结构：archive_completeness_rule(rule_id,field_path,applicable_lifecycle,rule_version,severity,repair_target)；check_result(equipment_id,rule_id,result,message,source_revision,checked_at)。本批检查结果实时计算，不建重复主数据表或永久修复任务表。

## 验收与遗留

93项本地规则测试通过，包括非法参数不写入、范围倒置、权限拒绝、缺项修复复查、多字段缺失一并修复以及禁止附带更改已有字段。浏览器验证数值/范围表单与13项规则分页；未在用户会话中提交参数或修改设备资料。

本批仍未覆盖枚举/布尔/文本参数、模板组合发布与适用绑定、全部PRD完整性规则、规则豁免审批、修复任务派发、正式后端。安装/拆卸/移位、保养和更换事务属于后续独立批次；不能将本批规则称为完整体系合规检查。
