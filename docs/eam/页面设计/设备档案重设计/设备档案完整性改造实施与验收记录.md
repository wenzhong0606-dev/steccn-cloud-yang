# 设备档案完整性改造实施与验收记录

日期：2026-10-12。范围：设备档案“档案完整性”页签，接续逐页签产品审查报告。预览端口：8765。新增统计、切换与筛选控件使用 Bootstrap。

## 已实现

- 汇总分别显示通过、缺失、待修正、未核验、不适用，并展示规则版本、检查时间（北京时间）、设备分类和生命周期。
- 明确区分登记检查项、明确适用必需项和未知适用项。未知项不进入明确必需项分母，不生成全档案完整率。
- 默认缺口优先；同级结果中明确必需项排在未知专业覆盖项之前。支持全部检查项、统计按钮、领域及结果筛选与重置。
- 基础字段沿用实际补录流程，保存后重新读取检查结果。图片、文档、参数、测点及专业覆盖项可进入对应页签；返回保留筛选。
- 详情保留规则版本、检查时间、适用口径与校验依据。最近正常检查快照按设备和角色保存在 sessionStorage；这不是后端持久化检查报告。
- 空结果明确表示没有完成检查，不解释为全部通过。

## 适用规则及限制

规则版本为 `COMPLETE-DEMO-V3`。专业演示适用范围为“生产设备 / 混合机”且型号 `MX-2400`，不代表其他设备或厂家标准。

参数行存在不能证明模板绑定已经核验。模板适用关系必须提供明确的分类、型号、模板及核验标记。未知分类、型号或生命周期的专业参数统一保留未核验，原数值校验不能使其计入通过。

图片、文档仅检查当前设备的有效关联。示例资料、仅元数据及本机内容读取失败均不能证明必需资料齐全。非示例内容可读取且非空，只证明内容存在，不证明资料业务有效性。示例混合机不要求 3D 模型，未上传不会形成必需缺口；草稿阶段不要求在用资料和运行测点。

15 个专业领域尚无必需项及适用规则，均显式保留未核验。已有业务记录或没有记录都不能直接推断完整性。测点配置检查不证明实时信号正常。

浏览器 EQ-001 快照为登记检查项 32、明确必需项 16，通过 13、缺失 0、待修正 0、未核验 18、不适用 1。图片页显示实拍 0 张、示意 2 张，与完整性页的图片未核验结果一致。这些数字随档案内容及规则变化，不是固定指标。
