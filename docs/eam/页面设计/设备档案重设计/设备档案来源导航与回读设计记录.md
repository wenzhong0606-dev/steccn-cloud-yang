# 设备档案来源导航与回读设计记录

日期：2026-10-11。范围：HTML模拟原型，不涉及正式数据库或后端发布。

## 交互规则

从设备档案进入点检、专项检查、异常、缺陷、故障、隐患、维修列表时携带equipment、returnEquipment、returnTab。列表按设备范围显示；未知设备返回零记录，不回退全量。来源详情检查记录所属设备，防止记录ID覆盖设备范围。

来源页面标题下提供“查看设备档案”链接，返回原设备、原页签与PC/移动视图，重新读取档案模拟接口。业务内连续跳转保留上下文；模块菜单进入全量业务入口，不沿用档案筛选。新建表单预选当前设备，显式改选其他设备时移除旧来源上下文。未实现筛选条件、页码和滚动位置恢复。

故障档案入口改为故障事件中心。无任意返回URL参数，页签限定在固定白名单。客户端范围校验不代替后端授权，原模拟API权限判断继续生效。

## 数据、方法与接口记录

| 项目 | 候选字段/方法 | 处理边界 |
| --- | --- | --- |
| 来源业务记录 | equipmentId、id、status、version | 沿用来源记录；正式表设计后统一外键与权限 |
| 导航上下文 | equipment、returnEquipment、returnTab、view | URL及前端上下文，不新增业务表字段 |
| 统一导航 | EamArchiveContext.navigate/filter/assertRecord；Eam.go | UI方法，非远程业务接口 |
| 档案读取 | GET /equipment/{id}/archive；GET /equipment/{id}/domains/{domain} | 继续异步模拟接口读取预定义JSON |
| 来源列表/详情 | GET /discoveries、/defects、/failures、/hazards、/work-orders及其详情 | 原型接口读取后按设备过滤；正式接口候选增加equipmentId过滤及服务端授权 |
| 点检/专项检查 | 现有任务读取接口 | 旧单设备样本的设备归属按EQ-001明确补齐；未来多设备任务应返回实际equipmentId |
| 创建与流转 | 现有POST及版本/幂等字段 | 本批不新增业务事务，不通过导航修改业务状态 |

## 验证与限制

新增5项上下文测试；全套100项本地测试通过。浏览器已观察点检任务、故障事件、维修列表入口携带EQ-001及原页签，档案返回链接匹配来源；维修详情实际导航到WO-2001并保留设备和来源。读取详情时浏览器调试器同步超时，未宣称详情回读、移动端上下文、模块菜单点击和创建改选已完成浏览器验收，这些保留为待复核。

未提交用户会话业务单据。安装、更换、保养、BOM、计量、成本等专业来源事务仍需逐项完善，本批导航贯通不等同所有专业业务闭环。
