# 设备档案模拟数据与展示边界

本文件为上一轮历史记录。当前展示和参数维护以[布局重做与模拟接口规范](设备档案布局重做与模拟接口规范.md)为准；不再在空白说明下追加样本区域。

更新：2026-10-10。版本：ARCHIVE-DEMO-V1；固定快照时间：2026-10-10 08:00。

为设备 EQ-001（1#混合机）补充16个领域、38条只读历史样本：概况、技术参数、位置安装、点检、保养、故障、维修、BOM、更换寿命、测点、运行读数、安全合规、成本、生命周期、审计、关联业务。图片和资料继续使用现有示例及本机上传记录；完整性继续核验现有基础字段，不虚构全域完整率。

数据独立存放在 `prototype/mock/archive-data.js`；小型展示脚本 `prototype/scripts/archive-demo.js` 只填充独立HTML中的指定样本区域。样本不写入 sessionStorage、不生成待办、不改变现有任务、状态、计划或用户数据。非EQ-001设备显示无此类历史样本，禁止跨设备复用。

每条样本可点击详情，展示设备、记录编号、内容、关联依据、版本及固定时间。样本关联编号只用于评审数据关系，不跳转到真实执行表单。历史状态与当前会话状态分开；当前操作仍以会话记录为准。成本样本演示权限允许设备工程师、管理层、审核人员查看，不等同后端授权。

关键关系：FLT-001故障 → REP-001维修 → RPL-001更换 → ACC-002验收；PM-001保养计划 → PMR-001完成记录；IP-001点检计划 → IR-001历史结果。轴承实例使用量10200−10000=200小时，目标8000小时，剩余7800小时。库存未接入，不伪造库存可用量；固定读数不称为实时采集。

候选表/字段及接口沿用[候选数据关系与接口边界](设备档案候选数据关系与接口边界.md)：参数值与模板版本、安装事件与功能位置、计划与执行结果、故障与工单、BOM版本与明细、零件实例与更换、计量器读数、安全适用性、成本来源、履历及字段审计。样本四列数组属于原型展示格式，不是正式数据库结构。本轮不新增正式表或接口；全量原型完成后统一设计。

验证：原有47条业务规则测试通过；独立样本校验核对唯一身份、关键跨域引用、寿命及保养周期。浏览器展示与详情交互证据以本轮实际检查为准，未开展真实服务验收。
