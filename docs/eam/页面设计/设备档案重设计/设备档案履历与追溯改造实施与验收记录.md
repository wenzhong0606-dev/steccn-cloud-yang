# 设备档案履历与追溯改造实施与验收记录

日期：2026-10-12。对应产品审查报告第18至20页签；范围为本地设备档案原型。

## 实现结果

生命周期默认展示时间线，可切换同源清单。搜索、来源类型、日期范围及分页共享条件，页签内切换与同页面切出再切回均保留已应用筛选。普通字段修改进入审计，明确业务状态变化及登记里程碑进入生命周期。真实生命周期命令的字符串前后状态兼容为 lifecycle 差异，停用事件不会丢失。

关联业务默认未结事项，支持全部关联、对象类型、搜索与日期筛选。按来源提供的 links、problemRefs、relatedRefs 连接分组，展示状态、责任、期限和关联引用；组号用于识别关联对象，不代表经过核实的独立问题数量。未结状态未知的历史样本在全部关联中保留，未提供的责任、期限和引用明确标注。

变更审计按操作时间倒序，支持操作者、字段、搜索、来源类型及日期筛选。详情包含操作时间、来源对象、原因与证据、版本和前后值；字段差异表保留零值、空值、嵌套字段及新增删除。没有快照的记录明确提示无法还原差异。差异表在只读详情弹窗中展示，避免嵌入清单操作列造成布局冲突。

新控件使用 Bootstrap。时间线按页展示，清单在窄屏横向滚动，主页面不横向溢出。加载、错误和空数据分别展示，错误可重试。存在实际来源入口时直接跳转，未接入的历史单据明确标注“来源入口未提供”，不伪造流程链接。

异常、缺陷和故障详情的“设备档案”按钮使用既有设备导航上下文。由关联业务进入异常 AB-1004，再返回设备档案，实际地址恢复 `equipment=EQ-001&tab=related`。

## 边界与后续

这些结果是本地原型与模拟接口证据，未取得真实后端或CI验证。采购、验收、投用等登记里程碑仍有历史示例，来源流程未接入时不能作为当前业务闭环证明。来源没有提供的操作者、日期、前后值和责任不能补造；无时间记录在全部范围保留，日期筛选不纳入。

筛选保留范围为当前档案页面会话内的页签切换；跨页面返回恢复设备与页签，尚未持久化全部筛选条件。页签仍使用 replaceState，不新增浏览器历史条目。审计未新增导出接口；正式上线时需由来源授权服务实现敏感字段遮罩与导出权限。

后续按审查报告推进档案完整性：定义分类与专业适用项、缺失／不适用／未核验的分母，再进行跨页签一致性验收。
