# 台账范围调整与档案覆盖矩阵

> 最新PRD及用户回复恢复独立功能位置；本篇相反决定为历史记录。当前以PRD重设计模型为准。

日期：2026-10-10。按用户最新决定覆盖此前功能位置/槽位方案。

## 最新边界

取消功能位置与槽位页面、导航入口、候选对象与7项接口；旧会话数据不再参与分类停用校验，保留历史快照而不擅自清空。设备继续维护所属位置，所属组织与责任独立；位置变更通过前后位置快照追溯，安装、更换保留设备实体身份。候选安装事件不包含slot_id/functional_location_id。分类与参数模板作为已有T01独立菜单，独立于台账操作；当前仍是单参数草稿维护切片，不宣称完整多参数模板已交付。

## 16模块与档案页签覆盖

| 附件信息模块 | 档案页签 | 当前能力及缺口 |
| --- | --- | --- |
| 基础信息 | 设备概况 | 当前资料与身份展示；Tag/资产属性仍待维护 |
| 设备层级 | 父子设备与部位 | 已有部位维护；独立父子设备关系未接入 |
| 安装位置 | 设备概况、安装与更换 | 所属位置及组织区；取消功能位置/槽位，历史快照模型待实现 |
| 技术参数 | 技术参数 | 模板独立入口；设备模板绑定/参数值尚未接入 |
| 组织与责任 | 设备概况 | 责任人已有；使用/管理部门/维修班组未维护 |
| 设备状态 | 顶部核心状态、测点运行与状态历史 | 保留多维状态；历史缺少来源时明确显示，不能伪造连续趋势 |
| 制造采购 | 设备概况 | 厂家/序列号已有；采购来源/供应商未维护 |
| 安装投运 | 设备概况、安装与更换 | 投用日期已有；验收/质保/装拆记录待实现 |
| 点检 | 点检任务与记录 | 当前示例任务/结果及标准计划入口 |
| 保养 | 保养计划与记录 | 策略/周期/最近下次/记录结构，业务来源尚未接入 |
| 故障维修 | 故障与维修 | 关联维修工单；独立故障与停机事件待实现 |
| BOM | BOM与备件 | 物料/数量/单位/实例/替换字段模型，当前无受控BOM来源 |
| 运行数采 | 测点运行与状态历史 | 人工读数已有；测点映射/运行小时/启停次数未接数采 |
| 安全合规 | 安全与合规 | 专业限制与独立解除已有示例；完整适用证据待扩展 |
| 资产成本 | 资产与成本 | 工时来源已有；金额/币种/财务映射未知 |
| 文档履历 | 图片与3D、技术文档、生命周期履历 | 多图/预览/权限、历史来源已模拟；真实模型/文件服务待集成 |

以上覆盖指信息架构、已有数据及缺口可见，不等于16模块CRUD完成。档案是业务聚合入口，各业务拥有自己的记录；未实施模块没有伪造可成功的新增按钮。技术文档、图片和履历始终在台账内，无独立菜单。
