# 表格空态与分页组件统一审查

日期：2026-10-11。范围：HTML 模拟原型，不涉及正式数据库或真实后端。

## 组件规则

所有实际表格由 `EamUiComponents.decorateTables` 装配 Bootstrap 表格、行内操作、load-status。`syncTableState` 在 tbody 内生成跨可见列的状态行，保留表头；状态行不计入业务记录数。加载、错误与空数据采用共享状态结构；已有记录刷新时保留业务行。列设置变更后同步空态 colspan。

无数据统一为“暂无数据 / 请调整筛选条件或刷新列表。”，旧表外提示节点隐藏，仅为旧脚本保留兼容引用。错误通过共享 load-status 提供重试。页面不得另外创建可见的列表空提示。

13 个主列表及档案记录清单调用 `pagination`，统计统一“共 N 条 · 第 P / M 页”，零条为第 1 / 1 页，换页按钮禁用。每页数量沿用业务配置：设备台账 10 条、问题及工单等 8 条、点检配置列表 5 条。详情中的逐项处理表完整展示相关项目，不强制分页。

## 浏览器验证

- 逐页打开 25 个入口，实际出现的表格均带 data-table 和 load-status；未出现可见的表外空态。部分入口为卡片、表单或旧入口跳转，无表格。
- 13 个主列表使用不匹配关键词，均显示表内空态和共 0 条分页；验证后恢复筛选值。
- 档案参数、结构、安装、点检、保养、故障、维修、BOM、更换、测点、趋势、风险、成本、履历、关联、审计、完整性共 17 个记录页签验证零结果；均使用共享表格和分页。
- 分类页在 1366×768、1024×600、390×844 下分页位于可见区域，未造成文档横向溢出。设备台账 12 条记录完成第一页到第二页再返回。
- 93 项本地 Node 回归测试通过；样式工程、设计一致性检查零错误。业务测试不等同于本次 UI 验证，也不代表真实后端验收。

证据：[浏览器检查记录](维护业务原型/表格组件统一浏览器检查.json)、[表内空态截图](维护业务原型/表格统一空态验收.png)。

## 字段与接口候选记录

本轮仅修改展示组件，不新增业务实体、数据库表或接口。候选分页响应仍为 items、total、page、pageSize；前端状态为 loading、loaded、empty、error，不能持久化为业务状态。筛选零结果和无权限/请求失败必须区分，失败不得推断业务数量为零。正式接口设计阶段统一服务端分页与授权范围；当前原型保持已有 JSON 模拟接口及前端分页。
