# 列表块头与筛选组件统一

日期：2026-10-10。

覆盖13个业务列表：设备台账、点检任务、专项检查、异常事件、缺陷、故障事件、隐患、维修工单、点检计划、路线、标准、分类参数模板、功能位置。

统一约定：
- 页面标题只承载业务名称与说明，点检任务/专项检查移除额外“业务清单”眉题及“列表”后缀。
- 列表容器头部为清单标题、搜索与筛选input-group、业务主操作。原有按钮ID及权限、数据方法保留。
- 搜索框外不显示重复文本标签；使用业务placeholder及aria-label。筛选按钮与搜索框为Bootstrap input-group直接子元素。
- 筛选展开区独立位于块头下，保留状态、我的相关记录和重置；按钮维护aria-expanded/aria-controls。分类与功能位置当前只有搜索，未虚构额外筛选业务。
- 桌面同一行，移动端在同一块头内按空间自然换行，不能为了强行同行压缩输入框与操作触达区。

验证：13页1366×768及390×844结构/溢出复查，均无页面横向溢出；专项检查关键词搜索进入空态、重置恢复2条记录，筛选展开/关闭正常。点检任务控件同行中心对齐已检查。样式与文档一致性检查均0错误。未新增业务字段、表或接口。

证据：列表块头统一验证.json、列表块头移动验证.json、专项检查-统一列表块头.png。
