# 设备导航树优化记录

日期：2026-10-10。

位置树由所属位置路径拆分为真实层级，设备组成树按设备与部位parentId展示，不再将整段位置作为单节点或平铺部位。位置/组成分支提供原生details折叠，保存页面内分支展开状态。节点使用统一线性SVG、Bootstrap按钮/缩进/边框/截断类；选中设备通过aria-pressed及主色表达。全部设备入口清除筛选，节点点击仍沿用现有列表筛选。

移动未显示原因：公共UI与设备脚本同时默认收起树；自动高度区域也缺少稳定高度。删除树的自动折叠逻辑，默认展开、允许手动收起；移动树面板220px，中间节点独立滚动，视图选择改为横排，避免挤占树内容。基础样式及业务接口未新增。

浏览器验证390×844树默认open、节点文本包含全部设备/车间/产线/设备；点击设备节点和切换设备组成/位置视图可用。82项模拟业务测试通过。截图：设备树优化-PC.png、设备树优化-移动端.png。


最新调整：设备导航容器不再使用details，始终显示；位置/组成改为标题同行的Bootstrap分段开关，移除全部设备。新增独立树筛选输入，匹配位置/设备名称编码/部位名称编码，保留匹配部位的祖先路径；树搜索不修改列表筛选。已验证无匹配提示、清空恢复、组成切换及移动展示，截图设备树开关与筛选-PC.png/移动端.png。覆盖此前导航容器可折叠与全部设备入口的说明。
