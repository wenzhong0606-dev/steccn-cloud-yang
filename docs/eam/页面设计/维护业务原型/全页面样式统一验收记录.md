# 全页面样式统一验收记录

日期：2026-10-10。基准：最新设备台账的Bootstrap表格、字体、容器与操作呈现。

## 统一范围

25个HTML入口统一加载公共版本，包含平台、工作台、设备档案、问题台账、维修执行、待验收、点检、标准、路线、计划及配置页面。旧defect入口保持既有跳转。独立HTML和JSON模拟业务数据/方法不改变，未生成整页JS。

- 所有静态及动态表格使用Bootstrap table/table-hover/align-middle，表头sticky-top/table-light，单元格使用间距与nowrap类，主副信息逐行截断并保留title。可编辑单元格的输入/选择/文本域保持原功能，不截断表单控件。
- 退出data-table及旧表格专属类，移动端采用原生横向响应式表格。状态使用Bootstrap badge/text-bg-*。现有按钮事件保留，操作最多两个直接按钮，其余更多；按钮保持同一行。
- 直接列表容器按可用高度分配，工具栏、读取提示、分页固定，表格区域内部滚动；详情与执行页保持原表单层级，内部表格限制高度并滚动。工作台保持角色指标及队列，PC宽屏四列指标，窄屏降列。
- 统一卡片内边距、区块标题、筛选控件和分页。新增全页面统一.css只治理业务布局；Bootstrap承担表格及控件外观。

## 验证

25入口在1366×768、390×844共50次基础浏览器检查：未发现文档横向溢出，未残留data-table展示类。明细见全页面统一双端检查.json。

实际查看异常列表、维修工单加载完成、创建工单弹窗和角色工作台；保留原有业务字段与按钮，未提交业务数据。截图：全页面统一-维修工单.png、全页面统一-工作台.png。

82项Node模拟业务测试通过，8个CSS文件样式工程检查通过，公共UI脚本语法检查通过。基础布局检查不等同于全部角色/状态的完整E2E或真实后端验收。

无新增正式或候选表字段、接口；各页面记录与原模拟API继续作为后续正式设计输入。
