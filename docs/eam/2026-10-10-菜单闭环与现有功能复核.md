## 1. 发现与修正

| 缺口 | 影响 | v0.2处理 |
| --- | --- | --- |
| PC工作台只定义通用聚合，移动端只有快捷入口区别 | 无法明确各角色待办、指标和工作范围 | 13角色定义内容、指标、动作和数据范围；多角色切换/去重 |
| 只核对MES核心设备接口 | 容易漏掉其他模块的设备相关能力 | 纳入采集重算、Platform IoT、工位配置及备件接口 |
| 未显式记录全量及单设备报表生成 | 原运行统计维护功能没有入口 | X06统计重算与数据对账，旧契约保留、重算防重复累加 |
| 趋势页缺趋势组CRUD与测点选择 | 只能看趋势，不能维护实际查询对象 | O05采集设备与测点、O06趋势组管理、查询导出 |
| 告警中心没有明确原平台规则/历史对应关系 | 规则及历史可能迁移遗漏 | X02增改查删/受控测试，O02原报警记录适配 |
| 工位设备直接排除 | 现有配置操作可能失去访问入口 | E05授权适配入口，配置权威仍归Platform |
| 计划生成失败/漏检无责任队列 | 无任务或任务过期时业务无法恢复 | I04跨计划类型生成异常、补生成、漏检及升级 |
| 外包仅有账号角色 | 缺少派单到交付的业务约束 | M06范围/资格/授权/交付/验收/成本关联 |
| 审核仅提供查看导出 | 审核发现没有登记与验证关闭入口 | D04发现与整改，关联R03措施，验证失败退回 |
| 退回、取消、缺料、资格失败等只隐含在审批中心 | 正向菜单看似完整，异常可能停滞 | 明确逐流程异常入口、责任人与关闭条件 |

## 4. 闭环设计结论与未验证边界

菜单v0.2第10节覆盖正向及退回/取消/延期/阻断/缺料/无人承接/数据失败路径。角色工作台第9节明确每条工作队列的处理者；主管处理无人受理，专业人员处理确认和验证，管理员处理技术异常。

设计复核范围内，A01-A27和B01-B11已明确入口或保留契约，发现的闭环入口缺口已在文档补齐。不能据此宣称全系统功能毫无遗漏：真实数据库菜单、外部旧前端、未暴露的遗留写入方及现场制度还未核验。

后续实现验收还需验证：各状态都有合法处理人及动作，所有退回可再次提交；权限/资格阻断提示责任人；审批和验收职责分离；通知失败可重试；领退料差异可结清；工单关闭不静默解除计量或检验限制；统计重算不重复累加；外部人员授权到期的任务转交；审核发现和纠正措施使用同一关联证据。

以上仅更新设计资料，无业务、数据库或菜单配置变更。原审批中心不代表节点已落地，新增菜单不代表流程已实现。
