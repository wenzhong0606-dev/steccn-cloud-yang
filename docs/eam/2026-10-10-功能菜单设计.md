## 1. 导航规则

- PC和移动端均从现有系统平台进入“设备管理”二级主页面；EAM不是独立门户，不重建平台首页、登录或全局导航。
- 页面层级：系统平台 → 设备管理模块（二级主页面） → 模块内角色工作台/业务列表 → 详情/执行。下文业务分组和60个菜单入口均属于模块内部，不是平台一级或二级主页面。
- 模块内部导航最多两级：业务分组 → 功能入口；无可见子项时隐藏分组。此限制不用于计算整个平台页面深度。
- 详情、创建、编辑、执行、验收、审批为页面或按钮，不再嵌套成第三级菜单。
- 工作台汇总我的待办，各业务菜单管理完整授权范围；待办跳转到同一业务记录，不形成独立副本。
- 角色只定义初始可见集合，数据权限、任务关系、状态和资格由后端联合判断。只读、编辑、派工、审批、导出、重试等权限分别配置。
- 条件能力按设备适用性启用：计量、专项检验、环境/能源关联等，没有授权数据且未启用能力时不展示。
- 本文路径为拟定的新前端路由，不是旧接口路径；不改变现有 Feign 服务名和 HTTP 契约。
- 为13类角色配置不同导航，不让普通现场人员看到全部管理员功能。

## 4. 移动端功能菜单

平台移动端 → 设备管理模块 → 角色工作台。模块内提供“工作台、任务、设备、我的作业”四个局部标签；它们不替换平台全局底部导航。模块标签放在内容区域，不与平台底栏叠加；独立页面模式也仅为模块局部导航并保持“返回平台”入口。

## 6. 权限与适用性实现约定

菜单权限使用 eam:<domain>:view；按钮权限使用独立动作，例如 eam:equipment:edit、eam:work-order:dispatch、eam:work-order:accept、eam:evidence:export、eam:integration:retry。最终命名在API规格阶段统一。

菜单配置字段：menuCode、parentCode、title、route、icon、sort、clientScope、viewPermission、capability、enabled。clientScope区分PC/移动/共用；不把用户数据权限直接固化到菜单配置。平台只注册设备管理模块入口与访问权限；模块内菜单挂在该模块上下文中，具体菜单存储方式按现有平台能力接入，不假定新建独立权限系统。

后端分别校验对象权限、组织/设备范围、任务授权、资格和状态。检索、统计、附件、导出同样受数据范围限制；复制详情链接不能越权。仅管理配置的R13没有默认的维修验收或计量确认权。

条件启用：计量菜单依据measurement能力；专项检验依据inspection能力；能源与环境关联依据energy/environment能力。适用性决定字段与作业规则，不按一个全局开关替代逐台设备判断。

默认角色导航是可调整模板；没有可见子菜单时隐藏父节点。用户跨角色共享一份待办列表，用标签筛选，不重复计数。

## 8. 菜单评审与验收

- 所有A01-A27既有能力有对应入口或保留的集成契约；新增N01-N10按业务页面覆盖。
- 现场角色PC导航保持精简；R01默认工作台、设备台账、点检任务/记录、缺陷台账及只读状态，管理配置不展示。
- 同一业务从工作台、菜单、二维码或深链接进入，显示相同版本和数据。
- 两端菜单、详情、按钮和实际后端权限一致；越权访问返回明确错误。
- 设备台账与测量设备、维修工单与保养任务等视图共用业务对象，避免重复建档或重复工单。
- 菜单无数据、未启用能力、无权限分别处理；因临时无数据不隐藏已授权核心菜单。
- 本轮只设计文档，不创建真实菜单数据库记录，也不修改应用权限、旧接口或业务代码。

## 11. 平台入口和返回规则

```text
系统平台（现有PC / 移动端）
└─ 设备管理（二级主页面，模块入口）
   ├─ 当前角色工作台（默认内容）
   ├─ 模块内业务导航（PC分组侧栏 / 移动局部标签）
   │  └─ 业务列表 → 详情 / 执行 / 审批
   └─ 返回系统平台
```

- 继承平台身份、组织上下文、主题、消息与权限；平台角色可映射到设备业务角色，不另建登录。
- PC面包屑为“系统平台 / 设备管理 / 业务 / 当前对象”；移动端返回优先回来源列表或任务，其次回模块工作台，模块首页可返回平台。
- 平台通知、二维码和深链接可直接到模块内任务；仍需平台鉴权与模块授权，登录后恢复目标地址。无权限不展示任务内容。
- 切换组织或角色会重算模块工作台及数据范围；返回平台不丢失未提交草稿，离线草稿按平台用户隔离，平台退出时清理敏感缓存。
- 57项是模块功能入口数量，不是57个平台主页面；不因平台挂载改变原有业务覆盖或职责分离。
- 验收增加：从平台进入/退出模块、两端全局导航保持、角色工作台默认落点、通知深链接、登录恢复、跨组织权限及返回栈。
