# 组件化闭环交付与验收记录

日期：2026-10-11。范围：HTML高保真原型组件化审核C01—C11与剩余公共结构迁移。业务数据继续使用现有JS预定义JSON及异步模拟接口；本轮不创建正式数据库和后端接口。

## 交付内容

- 30页页头均使用外部HTML片段。列表的head/body/footer、筛选input-group、分页、通用卡片和现有业务弹窗均已迁移适用结构；业务字段、表单、权限与操作按钮仍由独立页面定义。
- 修复checked多选收集、重复行顶层污染、原生格式/范围校验、必选多选组校验和错误恢复。旧提交回调仍收FormData；新表单可声明data-payload="json"或submitGuard第三参数typed=true，收类型化JSON。两种模式提交前均校验。
- 组件失败使用failed状态，必需组件失败阻断页面初始化；重试加载嵌套片段、增强并补做尚未运行的初始化。重复/并发加载复用同一实例；dispose移除通过Eam.listen/onDispose登记的监听及增强标记，重新加载替换骨架。页面启动期间禁止提前点击未绑定按钮。
- 台账、保养任务控制器支持root限定；Eam.find通过id/data-local-id查找，通用列表也支持第三参数root。分页保留前缀ID。默认页面仍使用单页实例兼容旧字段ID；组合页面必须给实例前缀并传root。
- 公共Tabs承担点击、键盘与ARIA，ui/interactions重复入口已删除。设备档案明确data-tabs-scope，档案控制器继续负责跨导航组互斥、URL上下文和实际业务接口加载；不把业务权限放到通用页签中。
- 弹窗关闭/取消/Esc统一接入退出保护；存在未保存输入时显示HTML确认框，继续编辑保留输入，放弃才关闭；submitGuard提交中阻止关闭并恢复按钮原禁用状态；既有弹窗onsubmit由adaptLegacy统一接入，保留原有成功关闭/跳转逻辑。接口成功关闭仍使用原生close，不再询问放弃。特殊只读弹窗可用data-confirm-exit="false"。
- 列表片段保持标题/页脚固定、主体和table容器可滚动；小屏/低高度允许主内容滚动，并为移动底栏预留空间。台账内联CSS抽入业务层、颜色回归Token；样式门禁按入口import layer检查，减少动画的可访问性important保留为唯一明确例外。
- 工具和依赖移到tools/eam/组件测试，node_modules已排除提交；文档保持中文名称。未修改用户的工作记忆文件。

## 结构例外与边界

设备导航树、统计卡、档案身份栏、图表/图库、运行时按接口生成的档案记录区保留业务专用结构；表格/筛选/分页调用原有EamUiComponents统一组件。不是把所有div强制换成通用卡片。dialog-content.html适配已有dialog与form宿主，避免dialog-shell旧演示骨架产生嵌套form。旧dialog-shell保留用于兼容试点，不推荐新业务页面使用。

dispose只负责已登记的组件资源，业务自行注册的定时器/订阅必须经onDispose清理。完整页面的全局服务保持单例；已运行区域的主动销毁重建必须显式调用相应root控制器，不把页面初始化函数全部重跑。失败的首次加载由loader自动恢复。

## 前端调用契约与数据设计记录

|调用|约定|
|---|---|
|Eam.loadComponents(root)|返回ok、instances、failed；失败状态不可当作已就绪|
|Eam.loadComponent(host)|同宿主并发/重复调用复用；主动重建须先dispose，再加载/增强/绑定root控制器|
|Eam.find(root, id)|按实例内id或data-local-id定位；业务组合场景不查询全局ID|
|Eam.Form.collect(form)、validate(form)|collect为类型化JSON；validate返回boolean，原生约束和自定义校验均生效|
|Eam.Dialog.submitGuard(form, callback, {typed:true})|callback收到JSON；默认旧回调继续收FormData；只有返回true才自动关闭|
|Eam.Dialog.adaptLegacy(root)|既有dialog表单onsubmit接入公共校验/忙碌保护，业务回调仍决定成功关闭或跳转|
|Eam.Dialog.requestClose(dialog)|关闭/取消/Esc统一入口；未保存显示HTML确认，忙碌时返回false|
|Eam.listen、onDispose|组件监听与订阅注册销毁回调；手工addEventListener不自动清理|
|initEquipment(root)、initMaintList(root)、EamList(records, options, root)|默认document兼容已有页面；多实例必须传独立root|

本轮增加的是前端组件契约和DOM隔离标识，未新增业务实体或数据库字段。原有各页字段/候选表/业务接口仍以页面数据与接口记录为准；正式数据库/接口统一设计继续按“全部模型完成后”执行。HTML片段通过现有HTTP原型服务器加载。
