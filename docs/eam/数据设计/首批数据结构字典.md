## 1. 通用字段与引用

持久业务记录：id（ID，主键，S）、tenant_id（按平台租户规则）、owner_org_id（ID，M/S）、created_by/created_at/updated_by/updated_at（ID/时间，S）、version（整数，S，乐观并发）、request_id（字符串，写入幂等）。组织、用户、班组、位置、字典使用平台权威ID；跨服务仅逻辑引用，不强建数据库外键。时间保留时区语义，统一存储约定后显示Asia/Shanghai。历史提交、发布、签署不覆盖删除；作废保存原因及审计。投影/事件表不机械套用可更新字段。

类型：ID=待确定统一标识类型；TEXT=文本；CODE=受控编码；TIME=时间；DECIMAL=固定精度数值（精度待物理设计）；JSON=版本化结构快照；BOOL=布尔；INT=整数。M提交必填、C条件必填、S系统生成。下表列出领域字段，通用字段另加；没有标M的字段不代表可以任意为空。

## 3. 状态与事务约定

- 点检：pending → active → submitted → complete；不需复核可提交直接complete。returned生成结果修订，取消保存原因；原型目前只演示pending/complete。
- 缺陷：open → accepted → processing → verified → closed；当前原型布尔值并未实现这些状态。
- 工单：assigned → active → awaiting → closed；验收退回returned → active，另有paused/cancelled；暂停/取消须恢复措施和原因规则。原型order=none仅代表无对象，不是数据库工单状态。
- 完工冻结execution_revision，验收关联该执行记录；同事务校验必验项、写验收/关联缺陷处置/工单状态及审计，不解除无关限制。
- 验收通过不机械设equipment_state健康正常：由全部未关闭缺陷、状态事件和判定规则计算；运行状态与健康状态独立。
- 点检提交/生成缺陷、派工/关联、完工/修订、验收/关闭各定义幂等和并发事务；外部库存/通知使用可靠事件与补偿。

工作台、列表和履历采用查询投影；平台/目录无需专属EAM业务表。每页查询响应除业务字段还包含对象id/version、可执行动作、范围、分页/口径与来源时间；命令使用request_id/expected_version，身份服务端绑定。正式URL和请求响应契约未设计完成。

## 4. 物理设计尚缺

数据库引擎与实际表核验；ID/租户/组织策略；每个字段的长度、精度、可空、默认及枚举；同库外键和跨服务引用区分；唯一约束与幂等键作用域；查询索引与历史分区；附件保留/法律保留；迁移映射与旧契约对账。此字典不能直接当作最终建表脚本。
