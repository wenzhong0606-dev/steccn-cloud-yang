# 设备管理设计资料管理规范

日期：2026-10-10。适用范围：本项目后续设备管理设计、原型及辅助工具。

- 文档：`docs/eam/`，Markdown文件使用中文名称；阶段文档可保留日期前缀。页面设计放`页面设计/`，实体/字段字典放`数据设计/`；全局续接入口为[设计与原型进度](设计与原型进度.md)。
- 工具：`tools/eam/`，生成和校验脚本不混入文档目录。现有[生成页面目录](../../tools/eam/生成页面目录.py)与[校验设计一致性](../../tools/eam/校验设计一致性.py)从仓库根运行；工具解析脚本位置定位文档，不依赖文档目录工作路径。
- 原型：`docs/eam/prototype/`，保留独立HTML及公共CSS/JS/模拟数据，属于可评审成果。HTML/JS/CSS名称保持现有路由和引用约定，文档中文命名不要求改产品代码文件名。使用说明、验证报告存放在文档区。
- 临时文件：优先内存/标准输入；确需落盘时使用明确的任务临时目录，结束后检查用途并删除本任务创建的临时文件，不删除未知文件或评审证据。正式生成的页面总表、原型及验证报告不是临时文件。
- 重命名/迁移：同步更新Markdown链接、工具输入输出路径和操作命令，再执行一致性校验；不只改文件名而遗留旧路径。
- 进度：完成/待做/历史验证分开记录，文件落盘不等于Git提交或远端备份。

本次整理：现有13份Markdown文档改为中文文件名，另新增本规范；2个Python工具移到tools/eam；原型使用说明及验证记录移出原型代码目录。检查未发现本范围内遗留临时文件，旧空目录已清理。

## 页面与后端设计记录规则（2026-10-10新增）

每个页面生成或修改必须同步保存候选表/字段结构、关系和接口列表，逐页记录页面ID、角色/场景、状态/操作、请求/返回/权限及验收边界。记录存于页面设计/页面记录，工具存于tools/eam；一致性校验必须检查所有HTML都有对应记录。

先完成所有页面模型与高保真，再依据记录统一设计正式数据库与接口。候选路径/字段不是正式接口契约，模型期不提前实施生产DDL/API。生成工具只管理登记/索引，页面保持独立HTML。

## 商业产品设计规则

所有页面按商业产品审计细节：对象上下文、责任人、权限查看/下载/维护分离、状态/版本、完整CRUD或合法替代、异常/空态、批量原子性、任务幂等与改派、PC/移动交互。图片、文档、模型及履历归设备台账；点检计划绑定岗位/人员，任务单一主责任人。每页同步候选字段和接口，所有模型完成后统一正式设计；不能将原型能力、前端权限或本机内容保存称为生产服务。

UI/UX公共规范见[HTML高保真页面UIUX审计与优化规范](页面设计/HTML高保真页面UIUX审计与优化规范.md)；页面变更同步逐页候选记录与审计证据，公共样式统一维护于prototype/shared/styles，门禁工具维护于tools/eam。
